Build Reproducibility Instructions – FraudShield AI

These instructions describe how to reproduce the FraudShield AI project locally, verify its functionality, and obtain consistent results.

 System Requirements

Operating System: Windows / macOS / Linux

Python: 3.9 or higher

Browser: Chrome / Firefox / Edge

Internet connection (required for threat-intelligence APIs)

 Step 1: Clone the Repository
git clone https://github.com/<your-username>/FraudShield-AI.git
cd FraudShield-AI

 Step 2: Create a Virtual Environment (Recommended)
python -m venv venv


Activate:

Windows

venv\Scripts\activate


macOS / Linux

source venv/bin/activate

 Step 3: Install Dependencies
pip install -r backend/requirements.txt


This installs all required backend libraries.

 Step 4: Configure API Keys

Open backend/config.py and add:

VIRUSTOTAL_API_KEY = "your_virustotal_api_key"


A free VirusTotal API key is sufficient for reproducibility.

Step 5: Run the Backend Server
cd backend
uvicorn main:app --reload


Expected output:

Running on http://127.0.0.1:8000


API documentation:

http://127.0.0.1:8000/docs

 Step 6: Run the Frontend

Navigate to the frontend/ folder

Open index.html in a browser

The frontend will connect to the backend automatically.

Step 7: Reproduce Core Features
🔹 SMS Scam Analysis

Paste a test scam SMS and verify:

Risk level

Scam type

Explanation

 URL Scan

Paste a suspicious URL and verify:

Multi-layer risk evaluation

Behavioral warnings even if threat-intel is clean

 File / APK Scan
